# 相机主体跟随与贝赛尔运镜 v1.2.1

入口：Blender 3D 视图右侧 N 面板 →「相机跟随」。先按 README 的安装步骤启用插件。

## 吸管拾取

「跟随主体」输入框右侧有独立的吸管按钮。点击吸管后，鼠标会变成吸管，再点击 3D 视图中的主体物体，或大纲中的物体行，即可直接指定主体。已经填入主体时，也可通过这个吸管重新选择。右键或 Esc 可取消，点到空白处或不符合类型的物体时可以继续重试。

下面的「使用选中物体」是另一种快捷方式：先选中主体，再点击此按钮。它不会进入吸管模式，图标已改为选择图标。

「路径曲线」和起始、结束参考相机的输入框旁也有独立吸管，分别只接受曲线或相机。路径吸管选好曲线后仍需点击「绑定摄像机」；参考相机吸管选好来源后仍需点击对应的记录按钮。吸管在物体模式下可用，拾取后保留原有物体选中状态。

## 选择起始画面和结束画面

新增的「首尾画面」位于「主体锁定与对焦」面板下，支持两种工作方式。

### 方式一：两个视角连接成新的可编辑路径

1. 选择画面来源：「当前视角」「当前摄像机」或「指定相机」。指定相机时，可分别通过吸管选择起始和结束的参考相机。
2. 将视角调整为想要的开头，点击「记录起始画面」。
3. 调整为想要的结尾，点击「记录结束画面」。
4. 设置构图方式、连接样式、侧向弯曲、中段抬升和控制点数量。
5. 设置输出动画的起始帧与结束帧，点击「连接首尾画面并生成运镜」。

生成的是可以继续移动控制点、细分、延伸的原生贝赛尔曲线。连接样式提供直线、弧线和 S 形。首尾位置相同也支持原地转向与变焦；此时若把零长度路径编辑成有长度的路线，需要重新点击「绑定摄像机」启用路径运动。

「匹配首尾构图」会过渡相机的位置、方向、焦距、偏移和正交比例，首尾构图对应记录的参考画面。「持续看向主体」会继续使用原有主体锁定，不接管原有焦距；如果记录画面本来没有对准主体，此模式不会保持原来偏离主体的取景方向。两种模式都可以继续对主体进行景深对焦。

从相机视图或指定相机记录可保留镜头构图；从普通透视视图记录时，会按场景渲染比例适配垂直视野。首尾参考需使用相同的透视或正交投影类型。

每个记录按钮旁的眼睛可预览已记录画面。预览使用局部参考相机和记录时的帧号，不更换场景渲染相机；「返回当前相机」恢复原来的视图选项与帧号。记录的是相机取景，不会复制场景物体、灯光或它们的动画状态；输出画面中的场景状态仍以输出动画的帧号为准。

重复记录同一端会更新其参考相机。参考相机保存在「相机运镜路径」集合中，随 .blend 一同保存。

### 方式二：在已有贝赛尔曲线上选择首尾画面

1. 绑定已有曲线，并保留手动编辑好的控制点。
2. 将「画面来源」切为「当前摄像机」。
3. 拖动时间轴，或清除路径进度动画后拖动「路径进度」，到想要开始的位置，点击「记录起始画面」。
4. 到想要结束的位置，点击「记录结束画面」。
5. 设置输出帧段，点击「已有路径仅播放首尾之间」。

这会使用记录的两个路径进度重新生成动画，不改曲线形状。两个画面必须从同一条已绑定路径的当前摄像机记录。起始进度大于结束进度时，会沿曲线反向经过这一段。对于闭合曲线，选择的进度按数值区间插值，不会自动跨越 1→0 的接缝。

「运镜动画」中也可直接设置「从」「到」两个进度值，再点击「生成 / 更新运镜动画」，实现不记录画面的路径截段。

首尾构图动画使用独立方向控制器及相机镜头数据副本。原有相机位置与镜头关键帧保留；关闭路径运动、解绑，或切回持续看向主体时，原有镜头数据可恢复。更换普通路径预设后，会恢复原有主体跟随和镜头动画。

## 创建一段运镜

1. 在「主体锁定与对焦」选择摄像机，用「跟随主体」右侧吸管选中主体。摄像机选择框旁的 + 可以从当前视角新建摄像机。
2. 在「贝赛尔路径预设」选择路径样式。可以先点「按主体估算尺寸」，再调整半径、基础高度等参数。
3. 在「运镜动画」设定起止帧、速度变化、循环方式及是否反向。
4. 点击「创建预设并绑定相机」。默认会创建曲线、绑定相机、生成动画，并跳到起始帧。
5. 点击「相机视图」和「播放」检查效果。

没有指定主体时，创建预设会在路径中心新建一个空物体作为对焦中心；以后可以通过主体吸管换成实际物体。

## 14 种路径样式

| 样式 | 运动特征 | 主要参数 |
| --- | --- | --- |
| 圆形环绕 | 闭合一周 | 半径、高度 |
| 椭圆环绕 | 闭合椭圆，距离发生变化 | 半径、高度 |
| 90° 弧线 | 四分之一圆弧 | 半径、高度 |
| 180° 半环绕 | 半圆弧 | 半径、高度 |
| 推进 | 从远处沿直线接近主体 | 距离、行程、高度 |
| 拉远 | 从近处沿直线远离主体 | 距离、行程、高度 |
| 左右横移 | 从主体前方横向经过 | 距离、行程、高度 |
| 垂直升降 | 固定水平距离，上升或下降 | 距离、高度、升降幅度 |
| S 形穿行 | 前进并左右摆动 | 半径、行程、高度 |
| 螺旋升降 | 旋转并逐渐改变高度 | 半径、圈数、升降幅度 |
| 螺旋收拢 | 旋转并逐渐缩小半径 | 半径、圈数、升降幅度 |
| 8 字环绕 | 闭合 8 字路线 | 半径、高度 |
| 波浪穿行 | 横向摆动与垂直起伏 | 半径、行程、升降幅度 |
| 拱形飞越 | 从一侧经过，同时升高再降低 | 距离、行程、升降幅度 |

「控制点数」决定初始贝赛尔控制点数量，范围 4–256；螺旋圈数较多时应增加控制点数。预设使用自动平滑手柄，可以在编辑模式改成其他手柄类型。

「路径中心」可选主体原点、3D 游标或世界原点。起始方向会参考创建时摄像机相对中心的朝向，「起始角度」在此基础上旋转。升降幅度可以为负数。

开启「路径随主体平移」后，创建或重建的路径会整体随当时指定的主体移动，保留世界朝向。此设置在创建或重建时应用，不会因更换对焦主体自动改绑已有路径的中心。

## 添加和编辑控制点

在「路径绑定与控制点」中：

- 「选中路径」：选中整条曲线，可以移动、旋转、缩放。
- 「编辑控制点」：进入 Blender 原生曲线编辑模式。
- 「细分加点」：在选中的曲段之间插入控制点；先选择相邻的控制点或全选，再细分。
- 「延伸点」：从选中的端点延伸，鼠标移动后确认新点位置。闭合路径需要先取消「闭合路径」，才能形成可延伸的端点。
- 「反转曲线」：反转控制点顺序，也会改变沿路径前进的方向。
- 「完成编辑」：退出编辑模式。
- 「闭合路径」：连接首尾，或将闭合路径改成开放路径。

修改预设参数后，已有曲线不会立即变形。「按参数重建路径」才会替换已有控制点，并保留曲线对象的位置、旋转和缩放。重建前会出现确认框，因为手动编辑过的控制点会被替换。

反复点击「创建预设并绑定相机」会保留旧曲线、创建新曲线，并将当前摄像机改绑到新曲线。旧曲线可以在大纲的「相机运镜路径」集合中找到。

## 使用已有曲线

用「路径曲线」右侧吸管选取曲线，再点「绑定摄像机」；也可以先选中曲线，再点「绑定选中曲线」。可以绑定自己画的贝赛尔曲线，也支持 Blender 原生可用的其他曲线路径。多段曲线使用 Blender 原生路径规则，建议每个路径对象只保留一条连续样条。

绑定已有曲线前，可先选好跟随主体。绑定操作只接管相机位置，已有主体锁定和景深对焦会继续工作。

## 动画与预览

- 起始帧 / 结束帧：规定通过整条路径的帧段，结束帧必须大于起始帧。
- 匀速：线性路径进度；曲线计算精度会影响实际速度的细微变化。
- 柔和启停：起点与终点速度为零，平滑加减速。
- 正弦缓动：以正弦方式加减速。
- 单次：在首尾帧以外保持端点位置。
- 重复：重复通过路径，开放曲线会从终点跳回起点；无缝循环适合闭合曲线。
- 往返：沿同一条路径来回运动。
- 反向运动：从终点走向起点。
- 同步场景帧范围：仅在勾选时，生成动画才会修改场景起止帧。

修改动画选项后，点击「生成 / 更新运镜动画」应用。它只替换独立路径控制器的进度关键帧，不改相机原有关键帧。

「路径进度」可手动拖动。若已经有进度动画，拖动后的值会在切换帧时重新由动画计算；点击生成动画按钮旁的空心关键帧图标，可清除生成的运镜动画，再手动预览。首尾构图模式下，此操作也会清除生成的方向和镜头参数关键帧，冻结当前取景；手动进度只改变位置，完整构图过渡应通过时间轴预览。关闭「创建时生成动画」后创建的普通预设路径也可以直接手动预览。

关闭「启用路径运动」会暂时显示相机原有位置和动画，重新开启即可恢复路径运动。「解绑」会移除本插件的位置约束，恢复相机原有位置及动画，同时保留路径和控制器供再次使用。

## 主体对焦

「持续朝向主体」和「景深自动对焦」可分别开关。跟随点为主体原点；需要对准模型上的具体位置时，可以在该位置新建空物体，将其父级设为模型，再用吸管选取空物体。

「光圈 F 值」越小，背景虚化通常越明显。主体选择旁的 X 可以解除主体锁定，并恢复插件接管前的对焦设置；解除主体锁定不会同时解绑运动路径。

插件不会自动避开遮挡或碰撞，也不会自动调整焦距来保持主体的画面大小。相机沿路径靠近或远离主体时，主体在画面中的大小会变化。

## 安装与保存

安装插件不会自动保存或覆盖 .blend 文件；需要保留新建的路径和主体选择时，请正常保存自己的工程。

可以通过「编辑 > 偏好设置 > 插件 > 从磁盘安装」选择 `camera_subject_follow.zip` 或 `camera_subject_follow.py`，再启用 Camera Subject Follow。

运镜使用 Blender 原生 Follow Path、Copy Location、Track To 约束和关键帧，景深使用原生焦点物体。保存 .blend 后，在未安装插件的电脑上打开，已有路径动画和对焦也能继续工作；使用本插件面板修改设置仍需安装插件。
