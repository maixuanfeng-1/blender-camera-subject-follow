# Changelog

## Documentation and demo update — 2026-11-16

- Three real camera moves rendered through the existing add-on: orbit, dolly in and rising helix.
- Added 16-second English/Chinese landscape videos, a Chinese portrait video and a looping preview.
- Added a bilingual demo page, a three-minute example task and a trial feedback form.
- Installer and core add-on behavior remain at 1.2.1.

## 1.2.1 — first public GitHub release

- Independent modal eyedroppers for subject, path and shot-reference cameras, including cancel/retry behavior and preservation of object selection.
- Includes all 1.2 and 1.1 features below.
- Public distribution adds English/Chinese documentation, an original editable demo scene, actual motion previews, a reproducible ZIP builder, GPL-3.0-or-later licensing and existing integration suites adapted for contributors.
- Core rig behavior is unchanged from the original 1.2.1 development version.

## 1.2 — original development version

- Record start/end frames from viewport, current camera or reference cameras.
- Connect endpoints with editable straight, arc or S-shaped paths.
- Match endpoint orientation/lens framing or keep tracking the subject.
- Play a recorded interval on an existing path without replacing its control points.

## 1.1 — original development version

- Fourteen editable Bézier presets and camera binding.
- Native point editing, subdivision, extension, reversal and closed/open curves.
- Progress timing, easing, repeat, ping-pong and reverse playback.
- Pause/unbind restoration and optional path translation with the subject.

## 1.0 — original development version

- Subject aim tracking and depth-of-field target focus from a sidebar.
- Preserve original focus settings when releasing the target.
